# Coding-agent skill: Calia Lab brand system
Read `brand/README.md`, `brand/foundations.md`, `brand/components.md`, `brand/voice.md`, and `brand/motion.md` before making brand changes.
Use `brand/assets/tokens.css` for every color and reusable size; semantic custom properties in components, no loose hex. CSS is scoped to guide use until integration is separately approved. Use Sora for headlines/accent and Inter for body; keep 48px targets, accessible contrast and visible focus.
Retain energetic color blocks, crisp layouts and at most one colorful curving line per composition. Never trace third-party logos or use unlicensed photography. Tone: warm, direct, evidence-led and empowering for women 40–50 with full schedules. Tagline: Más energía para todo lo que viene.
Never alter existing lab analysis logic, Clerk authentication, Vercel setup, reporting or app's existing typography and theme as part of a brand-kit-only change.
